معمولاتِ یومیہ — پرائیویٹ اینڈرائیڈ ایپ
===================================
یہ ایک Android پروجیکٹ ہے، تیار شدہ APK نہیں۔

اپنے Windows کمپیوٹر پر Node.js 22 یا اس سے جدید اور Android Studio انسٹال کریں۔
Android Studio میں Android SDK بھی انسٹال ہونا چاہیے۔
ZIP فائل Extract کریں اور BUILD_APK_WINDOWS.bat چلائیں۔
پہلی بار انٹرنیٹ چاہیے، کیونکہ npm اور Android کی ضروری فائلیں حاصل ہوں گی۔
اگر کامیاب ہو تو Mamulat_Yomiya_Private.apk بن جائے گی۔

اس APK کو آپ دوستوں اور گھر والوں کے ساتھ براہِ راست شیئر کر سکتے ہیں۔
ہر شخص کا ریکارڈ اسی کے موبائل میں الگ اور نجی رہے گا۔
عام استعمال کے لیے انٹرنیٹ ضروری نہیں۔

پرانے HTML ایپ کا ڈیٹا خودکار طور پر منتقل نہیں ہوگا۔
HTML ایپ سے JSON بیک اَپ Export کریں، پھر Android ایپ میں Import کریں۔
فون بدلنے یا ایپ Uninstall کرنے سے پہلے بیک اَپ ضرور بنائیں۔

اہم: آئندہ اپڈیٹ کے لیے ایک ہی ایپ شناخت (package ID) اور signing key استعمال کریں۔
